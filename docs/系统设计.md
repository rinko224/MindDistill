# 系统设计

## 系统架构图

```
用户浏览器
    │
    ▼
┌──────────────┐
│  React SPA   │  ← 教材上传 / 图谱可视化 / RAG问答 / 对话
└──────────────┘
    │
    │ HTTP / REST
    ▼
┌──────────────┐
│   FastAPI    │  ← 路由层 (routers/)
└──────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  业务服务层 (services/)              │
│  ├── ParserService    教材解析      │
│  ├── GraphBuilderService 图谱构建   │
│  ├── MergerService    跨教材整合    │
│  ├── RAGService       检索问答      │
│  ├── ChatService      对话调优      │
│  └── ReportService    报告生成      │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  工具层 (utils/)                     │
│  ├── LLMClient        OpenAI/本地   │
│  └── EmbeddingService 向量编码      │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  数据层                              │
│  ├── 文件存储  data/uploaded/       │
│  ├── 图谱数据  data/graphs/*.json   │
│  ├── 向量库    data/vectors/        │
│  └── 内存状态  StorageService       │
└─────────────────────────────────────┘
```

## API 接口一览

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/upload/ | 上传教材文件 |
| GET  | /api/upload/ | 获取教材列表 |
| POST | /api/parse/{book_id} | 触发解析 |
| GET  | /api/parse/{book_id}/status | 查询解析状态 |
| POST | /api/graph/build/{book_id} | 构建知识图谱 |
| GET  | /api/graph/{book_id} | 获取单本图谱 |
| GET  | /api/graph/merged | 获取整合后图谱 |
| POST | /api/merge/ | 执行跨教材整合 |
| GET  | /api/merge/decisions | 获取整合决策 |
| GET  | /api/merge/result | 获取整合结果 |
| POST | /api/rag/index | 建立 RAG 索引 |
| POST | /api/rag/query | RAG 问答 |
| GET  | /api/rag/status | 索引状态 |
| POST | /api/chat/ | 多轮对话 |
| POST | /api/report/generate | 生成报告 |

## 技术选型

- **FastAPI**: 异步高性能，自动 Swagger 文档，Pydantic 校验
- **React + Vite**: 轻量快速，生态成熟
- **ECharts**: 力导向图开箱即用，中文文档丰富
- **ChromaDB**: Python 原生，无需额外服务，适合比赛快速搭建
- **sentence-transformers**: 本地 Embedding，零 API 费用，低延迟
