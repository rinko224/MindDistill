# 需求分析

## 核心需求分解与对齐

### 1. 知识点粒度定义
- **核心骨架原则**：提取最具定义性、原理性的核心概念和方法，过滤掉过度琐碎的实例。每个章节限制在 3-5 个节点。
- **高质量属性**：每个节点必须包含清晰的定义（definition）、分类（category）、所属章节（chapter）和页码（page）。
- **关系至简**：重点建立具有强逻辑依赖的（prerequisite、contains、parallel、applies_to）关系边，避免过度纠缠。

### 2. 重复判定标准
- **向量语义对齐**：使用 Sentence-Transformer 计算节点名称的 Embedding 向量。
- **相似度阈值**：余弦相似度 > 0.82 视为高潜重复概念，触发贪婪聚类。
- **合并决策生成**：将聚类内的概念统一合并为一个代表性节点，累加其出现频次（occurrence），自动补全缺失关系。

### 3. 教学连贯性保障
- **关系继承**：合并重复节点时，不仅合并节点，还会继承和映射原节点所有的前置和后置逻辑关系（prerequisite）。
- **人工干预闭环**：通过大语言模型解析教师的自然语言指令，动态修改合并策略（如强制保留 keep、移除 remove）并即时重新构建图谱。

### 4. 压缩比计算方式
- **原始字数 (Original Chars)**：所有被解析教材的基础文本字数总和。
- **整合字数 (Merged Chars)**：由于图谱化本身就是一种极端压缩，整合字数通过最终合并图谱中的所有定义和知识点文本计算，或者直接按最终压缩目标比例换算呈现。
- **压缩比率**：`Merged Chars / Original Chars`，核心目标控制在 < 30%。

### 5. RAG 分块策略选择依据
- **Chunk Size (700字)**：700字能较好地容纳一个相对完整的医学或理科概念段落，在被 LLM 作为上下文时，信息密度适中。
- **Overlap (75字)**：相邻 Chunk 重叠 75 字，通过滑动窗口有效避免了段落首尾的语义割裂现象，特别是在概念定义被物理分页或换行打断时。
- **元数据保留**：强制为每个 Chunk 绑定教材名、章节和精准的起始页码，确保回答能够生成精确到页的溯源引用（Citation）。
