# 需求分析

## 子问题分解

### 1. 知识点粒度定义
- 以教材章节为单位，逐章提取核心概念、定理、方法、现象
- 每个知识点至少包含：名称、定义、类别、章节、页码
- 粒度控制在 "概念级"，不过细到公式或例题

### 2. 重复判定标准
- Embedding 余弦相似度 > 0.82 视为候选重复
- 候选重复对再经 LLM 二判，确认是否语义等价
- 支持同义词、中英文混排、不同表述方式的识别

### 3. 教学连贯性保障
- 保留知识点之间的 prerequisite（前置依赖）关系
- 整合时禁止删除存在被依赖关系的节点
- 压缩比以总字数为硬约束（≤ 30%），优先合并冗余，谨慎删除

### 4. 压缩比计算方式
- 原始总字数 = 所有教材 chapters 的 char_count 之和
- 整合后字数 = merged_graph 中保留节点关联的原文内容字数
- ratio = merged_chars / original_chars

### 5. RAG 分块策略选择依据
- 分块大小：600 字（兼顾上下文完整性与检索精度）
- 重叠长度：100 字（防止知识点被截断）
- 元数据保留：教材名、章节、起始页码，确保引用可追溯
